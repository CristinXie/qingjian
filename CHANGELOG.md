# Changelog

## [0.1.0] - 2026-08-03

Initial public release.

- Local Markdown notes with WYSIWYG and source editing.
- Search, favorites, folders, batch actions, and a 30-day recycle bin.
- Global quick notes and a configurable desktop todo widget.
- System tray behavior, startup settings, and single-instance activation.
- Local image attachments and bundled Toast UI Editor assets.
- Windows installer with WebView2 Runtime bootstrapper support.
