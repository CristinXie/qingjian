# Security Policy

## Supported Versions

Security fixes are considered for the latest release on the `main` branch.
Older releases may not receive fixes.

## Reporting A Vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for this repository:

<https://github.com/CristinXie/qingjian/security/advisories/new>

Include the affected version, reproduction steps, impact, and any suggested
mitigation. The maintainer will acknowledge reports when practical and will
coordinate disclosure after a fix is available.

## Data And Privacy Notes

QingJian stores notes, settings, and attachments locally under
`%LOCALAPPDATA%\QingJian`. The application does not provide cloud sync or
telemetry. Markdown network images and links opened externally may contact
third-party servers by design.
