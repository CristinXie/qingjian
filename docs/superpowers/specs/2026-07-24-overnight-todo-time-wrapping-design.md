# 跨天待办时间换行设计

## 目标

解决跨天待办时间包含“次日”后超出固定时间区域、结束时间不可见的问题。

## 显示规则

- 跨天时间由当前单行 `23:00-次日 01:00` 改为两行：第一行 `23:00-次日`，第二行 `01:00`。
- 当天时间范围继续显示为 `09:30-10:45`。
- 单时间待办、无时间待办及待办正文内容保持现有显示规则。
- 八日待办预览使用时间与正文组合文本，因此正文接在第二行结束时间之后，例如 `01:00 夜间值班`。

## 适用界面

统一换行规则覆盖所有使用待办时间转换器的界面：

- 八日待办预览。
- 桌面今日待办列表。
- 月历日期待办预览。
- 编辑待办列表。

## 实现方式

继续由 `TodoTimeDisplayConverter` 负责所有时间文本格式化。跨天范围返回包含换行符的字符串，现有 XAML 绑定和固定时间列宽保持不变。`TodoPreviewDisplayConverter` 继续复用该转换器，因此八日预览自动采用同一规则。

不在各个 XAML 模板中重复跨天判断，也不加宽时间列，以免压缩待办正文和产生多套格式化逻辑。

## 测试

- 转换器测试验证跨天范围输出 `23:00-次日\n01:00`。
- 组合预览测试验证输出 `23:00-次日\n01:00 夜间值班`。
- 既有测试继续验证当天范围、单时间和无时间显示不变。
- XAML 测试确认四个界面仍使用统一转换器，并允许绑定文本显示显式换行。
- 完整 Release 测试和 Release 构建通过。
