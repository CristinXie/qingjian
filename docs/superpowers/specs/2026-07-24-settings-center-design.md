# QingJian 设置中心设计

## 目标

将主窗口左下角现有的空设置入口实现为可用的设置中心，集中管理开机启动、编辑模式、快捷便签全局快捷键、桌面待办偏好、数据目录信息和运行环境信息。

首版只提供能够真实生效并可靠持久化的设置。不加入托盘、关闭时最小化、备份恢复、主题、云同步、提醒或语言切换。

## 窗口与导航

设置使用主窗口拥有的独立模态窗口，同一时间只允许存在一个设置窗口。窗口初始尺寸和最小尺寸均为 720 x 560 DIP，避免紧凑布局发生重叠。

- 左侧为固定宽度分类导航，依次为：常规、编辑、快捷便签、桌面待办、数据、关于。
- 右侧显示当前分类内容，使用无卡片嵌套的设置行布局。
- 每行左侧是名称和必要的简短状态文字，右侧使用符合值类型的控件：二元状态用开关或复选框，模式用分段选择，透明度用滑块，路径用只读文本和图标按钮。
- 图标按钮无边框、无按钮格底色，并使用立即出现的中文悬浮提示。
- 窗口底部右侧放置“取消”和“保存”文字按钮，圆角半径为 8 DIP，间距为 8 DIP。
- `Esc` 等同取消；保存成功后关闭窗口。关闭按钮等同取消。

所有可编辑内容先写入窗口草稿。取消或直接关闭窗口不会修改持久化设置或当前运行状态。

## 常规

常规分类包含“开机自动启动 QingJian”开关，默认关闭。

- 使用当前 Windows 用户的启动项，不请求管理员权限。
- 启动项位于 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名为 `QingJian`。
- 启动命令使用带引号的当前应用可执行文件完整路径。
- 启动项的实际注册状态是界面显示的事实来源，避免注册表和 `settings.json` 存在两份冲突状态。
- 注册表读写失败时保持原状态，设置窗口不关闭，并显示中文错误。

不提供“启动时隐藏主窗口”。应用继续使用 `OnMainWindowClose`，关闭主窗口即退出。

## 编辑

编辑分类包含“默认编辑模式”，可选“所见即所得”和 `Markdown`。

- 初始值复用现有 `AppSettings.EditorMode`。
- 保存后立即切换当前主窗口编辑器模式。
- 后续启动继续恢复所选模式。
- 不改变正文 Markdown 存储、自动保存、撤销历史或模式切换按钮行为。

首版不增加字体、字号、统计显隐或新建便签焦点设置。

## 快捷便签

快捷便签分类包含“启用全局快捷键”开关和一个只读快捷键录入框，默认启用 `Ctrl + Alt + N`。

- 开关关闭时不注册全局快捷键，快捷键录入框禁用，但已配置组合仍保留。
- 开关打开时必须存在有效组合。
- 用户聚焦录入框后直接按下组合键；单独按修饰键不结束录入。
- 有效组合必须包含至少一个 `Ctrl`、`Alt`、`Shift` 或 `Win` 修饰键，以及一个非修饰键。
- `Backspace` 清空当前草稿组合；`Esc` 不修改组合并关闭设置窗口，因此不作为可录入快捷键。
- 显示文本按 `Ctrl + Alt + N` 的格式生成。
- 保存时先尝试替换运行中的快捷键。若新组合被其他应用占用，则恢复原快捷键、不持久化任何设置、保持窗口打开，并显示“快捷键已被其他应用占用，请重新设置。”。
- 禁用快捷键保存成功后，当前会话立即停止响应原组合；重新启用后立即注册新组合。

快捷便签窗口内容和保存行为保持不变。

## 桌面待办

桌面待办分类包含：

- “显示桌面待办”开关。
- 显示模式：八日、今日、月历。
- 透明度滑块，继续使用现有 35% 到 95% 范围。
- “锁定桌面位置”开关。
- “恢复默认位置和外观”命令。

保存后，可见性、模式、透明度和锁定状态立即应用到当前桌面待办并持久化。设置窗口不直接编辑位置坐标；普通保存必须保留用户在窗口打开期间移动后的最新位置和当前月历月份。

“恢复默认位置和外观”只修改草稿并显示待保存状态。保存后将位置恢复为 `(80, 80)`、模式恢复为八日、透明度恢复为 75%、锁定状态恢复为关闭。该命令不强制改变“显示桌面待办”开关，也不修改待办数据。

桌面待办自身现有的模式、锁定、透明度和隐藏操作继续可用，并与设置中心写入同一份偏好。

## 数据

数据分类只读显示：

- 数据目录完整路径：`%LOCALAPPDATA%\QingJian` 的实际展开路径。
- 数据库 `qingjian.db` 占用空间。
- `attachments` 目录占用空间。
- 两者合计占用空间。

提供无边框文件夹图标按钮“打开数据目录”，通过 Windows 文件资源管理器打开目录。目录不存在时先创建。无法读取大小的文件应跳过，不阻止其余信息显示；无法打开目录时显示中文错误。

首版不提供备份、恢复、迁移、清理附件或删除数据。

## 关于

关于分类只读显示：

- 产品名 `QingJian`。
- 当前程序集版本。
- 当前 .NET 运行时描述。
- 已安装的 WebView2 Runtime 版本；无法读取时显示“未检测到”。

首版不增加网络更新检查。

## 设置模型与兼容性

`AppSettings` 保留现有编辑模式和桌面待办偏好，并新增快捷便签快捷键偏好：

- `IsEnabled`。
- `Modifiers`。
- `VirtualKey`。

旧版 `settings.json` 缺少快捷键字段时，规范化为启用的 `Ctrl + Alt + N`。无效修饰键、缺少普通键或无法识别的值也回退到默认组合。开机启动不写入 JSON，以 Windows 启动项为准。

设置保存通过同一更新入口串行写入 `settings.json`，避免编辑器模式、快捷键和桌面待办分别进行“读取后覆盖写入”时丢失较新的字段。

## 运行时协调与失败处理

设置保存按以下边界执行：

1. 在内存中验证全部草稿，包括快捷键组合。
2. 尝试替换全局快捷键，并在失败时恢复旧注册。
3. 尝试更新 Windows 启动项。
4. 将编辑模式、快捷键偏好和桌面待办偏好写入 `settings.json`。
5. 将编辑模式和桌面待办偏好应用到当前窗口。

保存前记录原启动项、原快捷键和原设置。任一步骤失败时依次恢复本次已修改的启动项、快捷键注册和设置文件，保持设置窗口打开，并显示具体中文错误；如果回滚本身失败，错误提示同时说明需要重新启动应用检查设置。数据和关于分类均为只读，不参与保存事务。

设置入口、窗口协调器、快捷键协调器、启动项服务和数据目录服务使用明确接口，方便在自动化测试中替换 Windows 注册表、全局热键和资源管理器调用。

## 测试

自动化测试至少覆盖：

- 旧设置文件加载时补齐默认快捷键偏好。
- 快捷键偏好规范化、组合验证和中文显示文本。
- 启用、禁用和替换快捷键；冲突时恢复原快捷键。
- 开机启动服务使用当前用户 Run 项和值名 `QingJian`。
- 设置保存成功时持久化并应用编辑模式和桌面待办偏好。
- 保存失败时保留原设置及原快捷键。
- 普通桌面待办设置保存保留最新位置和月历月份；重置命令应用默认位置和外观。
- 数据目录大小统计忽略不可读取文件，并正确计算数据库、附件和总大小。
- 设置窗口包含六个中文分类、正确控件类型、8 DIP 按钮圆角和即时中文工具提示。
- 主窗口设置按钮打开设置窗口，同一时间不重复创建。
- 完整 Release 测试和 Release 构建通过。

## 不在本次范围

- 系统托盘和关闭到托盘。
- 启动时隐藏主窗口。
- 备份、恢复、数据迁移或清理。
- 主题、自定义颜色、字体和语言切换。
- 云同步、账户、提醒和通知。
- 快捷便签内容布局或标题行为调整。
- 应用自动更新。
