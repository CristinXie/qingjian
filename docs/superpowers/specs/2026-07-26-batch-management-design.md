# QingJian 批量管理设计规格

## 目标

在主窗口现有便签导航中增加原地批量管理模式，让用户在当前文件夹、搜索条件和排序结果下选择多条便签，并完成批量移动、收藏、取消收藏和软删除。

本功能只修改 `feature/ui-polish` 工作树。进入批量模式前必须保存当前编辑器内容；批量操作不得改变便签正文、标题或 `UpdatedAt`，批量删除除外。

## 已采纳方案

### 方案比较

1. **主导航原地多选，采用。** 复用当前列表、分组、筛选和卡片样式，进入模式时把 WPF `ListBox` 从单选切为多选，并在卡片中显示复选框。上下文连续，重复 UI 最少。
2. **独立批量管理窗口，不采用。** 隔离清晰，但要复制搜索、分组、文件夹和卡片展示，还会产生主窗口与独立窗口状态同步问题。
3. **始终显示复选框，不采用。** 操作步骤少，但会长期占用卡片空间并增加误触，不符合当前安静、编辑优先的主界面。

### 范围

首版包含：

1. 批量移动到现有文件夹。
2. 从批量移动菜单新建文件夹并立即移动。
3. 批量收藏。
4. 批量取消收藏。
5. 批量软删除。
6. 全选当前结果、清空选择和退出批量模式。

首版不包含：导出、合并便签、标签、跨窗口选择、恢复已删除便签、批量修改标题或正文。

## 选择范围与模式生命周期

1. 点击左下角“批量管理”图标时，先从 WebView 拉取最新 Markdown，并立即保存当前便签。
2. 保存成功后，捕获此刻 `NotesView` 中全部可见便签 ID，作为本次批量模式的固定范围。
3. 当前文件夹、搜索词、时间/收藏排序及分组结果保持不变。
4. 批量模式期间禁用新建便签、搜索框、排序按钮、清除文件夹筛选、收藏按钮、卡片文件夹按钮和编辑区交互；普通底部工具栏隐藏。
5. 批量模式期间新产生的快捷便签不加入固定范围，退出后正常显示。
6. 退出批量模式时清空选择、解除范围限制、恢复普通单选和编辑器交互，并继续显示进入模式前的当前便签；若该便签已被删除或移出当前筛选，则选择原位置附近的下一条可见便签。
7. 当前结果为空时禁用“批量管理”入口。

## 主窗口交互

### 卡片选择

1. `NoteListBox` 在普通模式使用 `SelectionMode=Single`，批量模式使用 `SelectionMode=Multiple`。
2. 批量模式下每张卡片第一行左侧显示复选框；收藏星标隐藏。
3. 点击复选框或卡片空白区域切换选中状态，不改变编辑器中的 `SelectedNote`。
4. 选中卡片继续使用现有选中背景；标题、修改时间和文件夹三行布局保持稳定，不允许文本与复选框重叠。

### 批量操作栏

普通的设置、文件夹、批量管理工具栏在批量模式下替换为两行紧凑操作栏：

1. 第一行显示“已选择 X 项”，右侧依次为“全选当前结果”“清空选择”“退出批量管理”图标按钮。
2. 第二行依次为“移动到文件夹”“批量收藏”“批量取消收藏”“批量删除”图标按钮。
3. 所有按钮无边框、无按钮格底色，间距 8 DIP，使用 Segoe MDL2 Assets 图标，悬浮提示即时显示中文。
4. 未选择便签时四个写操作按钮禁用。
5. 所选便签全部已收藏时禁用“批量收藏”；全部未收藏时禁用“批量取消收藏”。
6. 移动菜单列出“未分类”和所有合法普通文件夹，并保留“新建文件夹…”入口；若全部所选便签已在某目标文件夹，该目标项禁用。

### 键盘

1. 批量模式下 `Ctrl+A` 全选固定范围内当前显示的全部便签。
2. `Delete` 打开批量删除确认框。
3. `Esc` 退出批量模式，不执行写操作。
4. 普通模式中的现有编辑器快捷键行为不变。

## 操作语义

### 批量收藏

1. 只修改尚未收藏的便签。
2. 同一次操作新增收藏使用同一个 UTC 时间作为 `FavoritedAt`。
3. 已收藏便签保留原收藏时间，避免无意义地改变收藏排序。
4. 不修改 `UpdatedAt`。

### 批量取消收藏

1. 只修改当前已收藏的便签。
2. 设置 `IsFavorite=false`、`FavoritedAt=null`。
3. 不修改 `UpdatedAt`。

### 批量移动

1. 目标文件夹通过 `IFolderService` 做一次完整校验。
2. 只更新尚未位于目标文件夹的便签。
3. 所有目标便签在一个 SQLite 原子更新中修改 `FolderName`。
4. 不修改 `UpdatedAt`。
5. 当前文件夹筛选中被移出的便签立即消失；“全部便签”视图中仍保留并更新第三行文件夹名称。
6. 文件夹计数在操作成功后刷新。

### 批量删除

1. 删除继续采用软删除，统一设置 `IsDeleted=true` 和同一个删除时间作为 `UpdatedAt`。
2. 执行前显示：`确定删除选中的 X 条便签吗？\n\n删除后暂时无法在应用内恢复。`
3. 使用“是/否”按钮，默认选择“否”。
4. 删除成功后从主窗口集合移除便签，并刷新文件夹计数。

### 操作后的选择

1. 每次成功操作后清空批量选择，但保持批量模式，方便继续选择其他便签。
2. 收藏操作按现有排序规则刷新列表。
3. 若普通 `SelectedNote` 在移动或删除后不可见，按操作前可见索引选择下一条；没有下一条时选择上一条；列表为空时设为 `null`。
4. 操作失败时保持批量模式、固定范围和全部勾选状态。

## 架构与数据流

### Repository

`INoteRepository` / `NoteRepository` 增加按去重 ID 集合执行的批量收藏、移动和软删除方法。实现使用 EF Core `ExecuteUpdateAsync`，每个批量动作只提交一个 SQLite 更新语句，因此动作本身具有原子性。

### Service

`INoteService` / `NoteService` 增加面向 `IReadOnlyCollection<Note>` 的批量方法。Service 负责：

1. 去重和过滤无需变化的便签。
2. 文件夹目标校验。
3. 为一次操作生成统一时间。
4. 先成功持久化，再更新内存中的 `Note`，避免失败回滚遗漏。

### MainViewModel

`MainViewModel` 负责批量模式、固定范围 ID、当前选择、按钮可用状态、操作后的集合变化、导航刷新和最近可见便签选择。固定范围参与 `FilterNote`，保证快捷便签或其他新数据不会在批量操作中途进入列表。

### MainWindow

`MainWindow` 只负责 WPF 多选同步、编辑器保存/禁用、图标按钮事件、文件夹菜单和确认/错误弹窗。数据库操作必须委托给 `MainViewModel` 和 Service，不在代码后置中直接访问 Repository。

## 错误处理

1. 进入批量模式前保存失败：不进入模式，显示“进入批量管理前无法保存当前便签”。
2. 批量收藏失败：显示“批量收藏失败”。
3. 批量取消收藏失败：显示“批量取消收藏失败”。
4. 批量移动失败：显示“批量移动便签失败”。
5. 批量删除失败：显示“批量删除便签失败”。
6. 具体异常消息放在第二段；失败时不得部分修改数据库、内存便签、列表或选择。

## 测试与验收

1. Repository 使用 SQLite 内存数据库验证空集合、重复 ID、原子更新、字段隔离和未匹配 ID。
2. Service 验证统一收藏时间、保留旧收藏时间、目标校验、无操作短路和失败时内存不变。
3. MainViewModel 验证固定范围、搜索/文件夹组合、快捷便签隔离、按钮状态、移动/删除后的最近项选择及失败选择保留。
4. XAML 测试验证多选触发器、复选框、两行批量操作栏、8 DIP 间距、无边框图标样式、中文即时工具提示和编辑区禁用状态。
5. 代码后置测试验证进入前保存、选择同步、文件夹菜单、确认文案、中文错误和键盘操作。
6. 最终执行全量 Release 测试、Release 构建和真实运行检查，确保 `develop` 工作树保持不变。
